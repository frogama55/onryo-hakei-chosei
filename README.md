# 音量波形調整

音量の調整を、波形を見ながら簡単に、直感的に行える macOS 用のフリーソフトです。
波形の上に点を打って上下に動かすだけで、その部分の音量を上げ下げできます。音声にも動画にも使えます。

> **開発中です。** 配布版はまだ公開していません。今のところ、下の「開発」の手順で動かせます。

- 1時間を超える長いファイルでも滑らかに編集できます
- 調整後の音量と、音割れする位置を確認しながら作業できます
- 動画は映像を再圧縮せず、音声だけを差し替えます
- ファイルはすべてこの Mac の中で処理します。インターネットには接続しません
- 元のファイルは変更しません

## 動作環境

macOS 15.5 以降、Apple シリコンの Mac（M1 以降）

## インストール

1. [Releases](../../releases) から最新の zip をダウンロードして開きます
2. `音量波形調整.app` を「アプリケーション」フォルダへ移します
3. アプリをダブルクリックします

このアプリには Apple の署名がないため、初回は警告が出て開けません。次の手順で開いてください。

4. 警告を閉じて、「システム設定」→「プライバシーとセキュリティ」を開きます
5. 下の方にある「このまま開く」を押します

## 使い方

ファイルを開くか、ウィンドウへドラッグします。

| やりたいこと | 操作 |
|---|---|
| 音量の点を打つ | 「✎ エンベロープ編集」を押して波形をクリック |
| 音量を変える | 黄色の点をドラッグ（+24〜-60 dB） |
| 点を消す | 右クリック（両端の点は消せません） |
| 取り消し / やり直し | ⌘Z / ⇧⌘Z |
| 拡大・縮小 | ⌘+スクロール、⌘= / ⌘-、全体表示は ⌘0 |
| 再生位置の移動 | 編集モード以外で波形をクリック |
| 再生 / 一時停止 | スペース |

### 画面の見方

- **青の波形**: 元の音量
- **緑の線**: 調整後の音量
- **上端の赤い印**: 音割れする位置（書き出す前にも確認が出ます）
- **赤・緑・青の背景**: 上限と下限で分けた音量の範囲（目安の表示で、音は変わりません）

### 保存と書き出し

編集内容は自動で保存され、同じファイルを開くと復元されます。

- **音声**: 保存するときの拡張子で形式が決まります（WAV / FLAC / M4A / MP3）。
  M4A と MP3 は再圧縮されます。音質を保つなら WAV か FLAC を選んでください
- **動画**: 最初の音声トラックだけを残します。字幕と2本目以降の音声は書き出されません

## 開発

```bash
pip install -r requirements.txt
brew install ffmpeg                         # 開発時は PATH の FFmpeg を使う
python main.py                              # 起動
python -m unittest discover -s tests -t .   # テスト
```

配布版を作る手順:

```bash
python -m venv --system-site-packages .venv-release
.venv-release/bin/python -m pip install pyinstaller==6.22.3
./scripts/build_ffmpeg.sh    # FFmpeg を LGPL の範囲でビルド
./scripts/build_release.sh   # .app と zip を作り、ライセンスの監査を行う
.venv-release/bin/python scripts/test_release.py dist/*.zip   # 各形式の動作を確認
```
