# 音量波形調整

音量の調整を、波形を見ながら簡単に、直感的に行える macOS 用のフリーソフトです。
波形をつまんで上下に動かすだけで、その部分の音量を上げ下げできます。音声にも動画にも使えます。

> **開発中です。** 配布版はまだ公開していません。今のところ、下の「開発」の手順で動かせます。

- 1時間を超える長いファイルでも滑らかに編集できます
- 調整後の音量と、音割れする位置を確認しながら作業できます
- 動画は映像を再圧縮せず、音声だけを差し替えます
- ファイルはすべてこの Mac の中で処理します。インターネットには接続しません
- 元のファイルは変更しません

## 動作環境

macOS 15.5 以降、Apple シリコンの Mac（M1 以降）

## インストール

1. [Releases](../../releases) から最新の zip をダウンロードして開きます
2. `音量波形調整.app` を「アプリケーション」フォルダへ移します
3. アプリをダブルクリックします

このアプリには Apple の署名がないため、初回は警告が出て開けません。次の手順で開いてください。

4. 警告を閉じて、「システム設定」→「プライバシーとセキュリティ」を開きます
5. 下の方にある「このまま開く」を押します

## 使い方

ファイルを開くか、ウィンドウへドラッグします。開いてすぐ「ドラッグ編集」で調整できます。

### ドラッグ編集（最初の状態）

| やりたいこと | 操作 |
|---|---|
| 音量を変える | 波形を上下にドラッグ。つまんだ所の波形がマウスに付いてきます |
| もう一度調整する | 波形の上の黄色の点をドラッグ |
| 点を消す | 右クリック（両端の点は消せません） |
| 再生位置の移動 | 波形をクリック（動かさずに離す） |

つまんだ位置の左右にも点が置かれ、その外側の音量は変わりません。
広い範囲を上げるときは、拡大してからつまむか、範囲の中を何か所かつまみます。
点線は調整前の波形です。

### ライン編集

音量の増減を黄色の線で表示し、線に点を打って動かします（+24〜-60 dB）。
細かく形を決めたいときに使います。

| やりたいこと | 操作 |
|---|---|
| 点を打つ | 波形をクリック |
| 音量を変える | 黄色の点をドラッグ（左右にも動かせます） |
| 点を消す | 右クリック |

緑の線は調整後の音量です。2つのモードは同じ調整を別の見方で表示しているので、途中で切り替えられます。

### 共通の操作

| やりたいこと | 操作 |
|---|---|
| 拡大・縮小（時間の方向） | 右上の「－」「＋」「全体」、⌘+スクロール、トラックパッドのピンチ、⌘= / ⌘- / ⌘0 |
| 左右に移動 | スクロール、または下のスクロールバー |
| 取り消し / やり直し | ⌘Z / ⇧⌘Z、または右下の「戻る」「進む」 |
| 前の状態まで戻す | 右下の「編集の履歴」で項目を押す |
| 再生 / 一時停止 | スペース |

### 編集の履歴

右下に、編集した内容と日時が順に並びます。項目を押すと、その時点の状態に戻ります。
戻った後も後ろの項目は薄く残り、押せば先へ進めます。そこから新しく編集すると、後ろの項目は消えます。
履歴は開いている間だけのもので、次に開いたときは最後の状態から始まります（最大100件）。

### 画面の見方

- **上端の赤い印**: 音割れする位置（書き出す前にも確認が出ます）
- **赤・緑・青の背景**: 上限と下限で分けた音量の範囲（目安の表示で、音は変わりません）

### 保存と書き出し

編集内容は自動で保存され、同じファイルを開くと復元されます。
音声や動画のファイルは書き出すまで作られないため、書き出さずに閉じようとすると確認が出ます。

- **音声**: 保存するときの拡張子で形式が決まります（WAV / FLAC / M4A / MP3）。
  M4A と MP3 は再圧縮されます。音質を保つなら WAV か FLAC を選んでください
- **動画**: 最初の音声トラックだけを残します。字幕と2本目以降の音声は書き出されません

## 開発

```bash
pip install -r requirements.txt
brew install ffmpeg                         # 開発時は PATH の FFmpeg を使う
python main.py                              # 起動
python -m unittest discover -s tests -t .   # テスト
```

```bash
.venv-release/bin/python -m pip install pyinstaller==6.22.3

./scripts/build_release.sh   # .app と zip を作り、ライセンスの監査を行う
```
